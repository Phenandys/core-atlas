# Project outcomes

- [x] **Angular project and CORE data source:** “Create a new Angular project using version 20 or higher.” “Review the API documentation for https://core.ac.uk/ which is an open API for free-to-use research paper data. Learn how to do a simple GET request to make queries. For example: https://api.core.ac.uk/v3/search/works?q=(drone).” The application uses Angular 20.3 and calls CORE’s works-search GET endpoint through its same-origin server proxy. Build and run instructions are in `README.md`.
- [x] **Boolean search and result count:** “Add a field for the user that lets them change how many papers are returned from the API.” “Add a search bar that allows users to search through the documents collected via a boolean keyword search,” including `(drone AND (package OR delivery))`. The query follows CORE’s documented Boolean syntax; users can choose 10, 20, 50, or 100 works per request.
- [x] **Paper discovery and filtering:** “Build a UI that presents these paper objects with a clean and intuitive design of your making.” The result list includes paper metadata and links, supports pagination and sorting, and lets users refine the currently returned page.
- [x] **Query chart:** “Add a chart to the design. The chart should aggregate data from all papers that match a given query.” “You can choose to find the chart information from the data stored client-side or from the API in aggregate.” “If no query has yet been entered, the chart can be blank.” CORE’s aggregation endpoint supplies the query-wide publication-year chart when available; a current-page fallback is labelled.
- [x] **Saved papers (added capability):** Save useful papers locally for later reference in this browser.
- [ ] **Repository and submission:** “Push your project to a public Github repo and send the link to hr@sterlingcode.org.” The repository should include “Build/run instructions in the README” and “Multiple commits building up the project, where the project is ‘working’ at each stage.” “Please be sure to enumerate anything you add when submitting your project.” The README contains build/run instructions and enumerates the added capabilities. Implementation and follow-up commits are recorded on the Manus project’s `origin/main`; the production build passes. Public repository `https://github.com/Phenandys/core-atlas` has been created and the project history pushed. The external email remains unsent pending separate confirmation.
